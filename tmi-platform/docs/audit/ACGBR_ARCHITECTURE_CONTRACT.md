## Honesty statement

ACGBR (Autonomous Cinematic & Generative Broadcast Runtime) is the **architecture contract** for cinematic presentation over Live Fabric / Jumbotron / Universal Player.

It does **not** claim:

- Neural lip-sync production nets
- Unconstrained live AI 3D generation
- Fake crowd fill / fabricated audience members
- Live blockers of the form “AI generating…”

**Live path:** certified procedural templates + deterministic seeds + HOT fallbacks.  
**Generation Foundry:** typed interfaces + certified template registries only (`GenerationFoundryContracts.ts`).

AI generation in this contract means procedural/templated runtime assembly with certified constraints.
It does not mean unconstrained in-show asset authoring that can block or override live truth.

## Global scene-chain taxonomy (all event families)

All experience families compose from a canonical chain envelope (policy branches allowed):

`PRE_EVENT -> TEASER -> PARTICIPANT_ARRIVAL -> OBJECTIVE_OR_CONTEXT -> ACTIVE -> JUDGMENT_OR_RESULT -> OUTRO`

Extended optional branches:

- `BACKUP_SCENE` (failure-safe render path)
- `CUT_SCENE` (short cinematic transition)
- `SAFE_BREAK` (sponsor/ad-safe intermission)
- `RECONNECT_RESUME` (elapsed-time rejoin path)
- `POST_RESULT_CHAIN` (rematch/next-up/return-to-world)

This chain is generated by deterministic seeds and capability-aware variants,
never by writing new authoritative outcomes.

---

## Autonomous showrunner loop (bounded)

ACGBR supports automatic scene variants and loop chains through certified bounded generation:

`INTENT -> CAPABILITY_RESOLVE -> TEMPLATE_VARIANT -> TIMELINE_BIND -> EXECUTE -> OBSERVE -> SCORE -> NEXT_VARIANT`

Hard constraints:

- No human drawing is required during runtime playback.
- Generation cannot block live progression waiting for novel assets.
- Any failed variant falls back to a certified HOT template.
- Loop chaining is bounded by budget and safety policy (no infinite unbounded graph growth).

---

## Facial performance and lip-sync policy

Two pipeline modes are ratified:

- System/AI character path:
  `dialogue facts -> generated line -> phoneme timing -> viseme track -> emotion envelope`
- Live human panel path:
  Real WebRTC source remains canonical media truth; ACGBR may animate panel motion/composition,
  but does not fabricate a replacement human face stream.

Emotion envelope fields are canonical:

`primaryEmotion`, `intensity`, `valence`, `arousal`, `gestureBias`

Any generated line that references stakes, winner, policy, timer, or settlement must be fact-envelope bound.

## World-wide execution scope

ACGBR is intended to execute across:

- Venues (stage, seating, walls, screens, jumbotron)
- Lobbies (fan/avatar where authorized)
- Lounges (video-panel presence law preserved)
- Rooms and event surfaces (battle/challenge/cypher/gauntlet/live/concert/release/game show)

This does not replace specialized world runtimes.
It orchestrates cinematic composition over canonical world/media systems.

## Freeze test (mandatory)

```text
ACGBR forbidden from writing Challenge truth — automate this.
```

Evidence:

- `assertAcgbrCannotWriteChallengeTruth(['winnerId'])` throws `AcgbrBoundaryViolation`
- `Object.freeze` on `ChallengeSnapshot`
- `finalizeResult()` with real stake → `settlementStatus: PENDING` (not SETTLED)
- `settleResult()` is the only path to SETTLED + settlementReference
- `resultFinalizedDoesNotImplyPayout(view)` for PENDING/EXEMPT
